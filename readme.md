DailyBoard adalah aplikasi web untuk membantu mengatur kegiatan sehari-hari.
Fitur

- Tambah, edit, selesai, coret, dan hapus tugas.
- Cari, filter, dan ubah urutan tugas.
- Tambah, edit, dan hapus catatan.
- Menampilkan kutipan harian.
- Cek cuaca berdasarkan kota.
- Dark mode.
- Data disimpan dengan Local Storage.
- Responsive untuk desktop, tablet, dan mobile.

Cara Menggunakan

1. Tugas— Masukkan tugas lalu klik 'Tambah'
2. Selesai — Klik tombol Selesai
3. Edit — Klik dua kali nama tugas.
4. Hapus — Klik tombol 'Hapus'
5. Cari & Filter — Gunakan kolom pencarian dan tombol 'Semua', 'Selesai', atau 'Belum Selesai'
6. Catatan— Tulis catatan lalu klik 'Tambah Catatan'
7. Cuaca — Masukkan nama kota lalu klik 'Cek Cuaca'
8. Dark Mode— Klik tombol tema di bagian atas

 Struktur File

- index.html > Struktur halaman.
- style.css > Tampilan dan responsive.
- script.js > Fungsi utama aplikasi.
- tugas.js > Fitur tugas.
- catatan.js > Fitur catatan.
- storage.js > Penyimpanan Local Storage.
- api.js > Mengambil data kutipan dan cuaca.
- README.md > Dokumentasi project.
